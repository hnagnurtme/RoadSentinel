RoadSentinel Backend - Minimal DDD+CQRS scaffold

Quick start (macOS / Linux):

Requirement:
- Python 3.13 (recommended). Python 3.14 currently causes `pydantic-core` build issues.

Environment config (`.env`, required):

```env
APP_NAME=RoadSentinel Backend
APP_ENV=development
APP_HOST=127.0.0.1
APP_PORT=8000
DATABASE_URL=postgresql://<user>:<password>@<host>:<port>/<db>?sslmode=require
SQL_ECHO=false
```

1. Create virtualenv and install deps:

```bash
/opt/homebrew/bin/python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Initialize DB (uses `DATABASE_URL` from `.env`):

```bash
# create tables without alembic
just init-db
```

3. Run the dev server:

```bash
just run
```

4. Migrations (alembic):

```bash
just upgrade                               # apply current migrations
just migrate message="your change"         # create autogenerated revision
just migrate-empty message="manual"        # create empty revision
just migrate-views message="refresh views" # create revision for PG views
just current                               # show current revision
```

Base URL:

- REST: `http://127.0.0.1:8000/api/v1`
- WebSocket: `ws://127.0.0.1:8000/api/v1/ws/alerts`

Response envelope:

```json
{
	"success": true,
	"message": "success",
	"data": {}
}
```

Health check:

- `GET /`

Current architecture:
- `domain/`: entity, value object, repository contract, domain service
- `application/`: command/query + handlers (CQRS)
- `infrastructure/`: SQLAlchemy model/session + repository implementation
- `interfaces/`: FastAPI dependencies, middleware, HTTP routes
